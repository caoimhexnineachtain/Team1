The Story

A penguin lives happily in a house built from magical ice in the Arctic. One year, a terrible drought leaves a cowboy's farm without enough water to keep his crops and animals alive. Desperate to save his ranch, the cowboy travels north after hearing legends of magical ice that never fully melts.

Unable to find another solution, the cowboy breaks apart the penguin's ice house and carries off the ice. During his journey home, chunks of the magical ice are scattered across the world. The penguin sets out to recover every piece before it's gone forever. Throughout the adventure, the cowboy constantly chases the penguin, trying to reclaim the ice he believes is the only way to save his farm.

How to Play It

Snow Place Like Home is a desktop game built in Python. It runs on your computer — not in the browser.

1️⃣

Install Python

Download and install Python 3 from python.org if you don't have it already.

2️⃣

Install Pygame

Open a terminal and run: pip install pygame

3️⃣

Download the Game

Download the project from our GitHub repository and unzip it.

4️⃣

Run the Game

Open a terminal in the project folder and run: python Leah/level_1.py

The game cannot be played inside a web browser — it needs Python and Pygame installed on your machine. Once you've run it once, it starts instantly every time.

Gameplay

The Gameplay Loop

Simple controls. Increasing challenge. One goal — get home.

🏃

RUN

The penguin keeps moving. Keep up!

⬆️

JUMP

Leap over obstacles in your path.

🚫

AVOID

Hitting obstacles drains your health.

🧊

COLLECT

Ice cubes are needed to progress to the next level.

💪

SURVIVE

Stay alive long enough to get home.

🏔️

GET HOME

Reach the Arctic. You made it!

What's in the Game

Every detail designed to make the journey feel real — and fun.

🚧Varied obstacles across each environment
