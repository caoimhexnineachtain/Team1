Behind the Scenes

How We Made It

From a doodle on Pixilart to a playable game — here's how the project came together, step by step.

💡

The Idea

At the beginning of the month we sat down to sketch a protagonist on Pixilart. Four different ideas got mashed together into one penguin in a cowboy hat, and the project took off from there.

🎨

Design

With the protagonist settled, we mapped out a storyline and levels using a mix of AI-assisted and hand-drawn design work.

💻

Programming

The game runs on Python and the Pygame library. Collision detection, the health system, scoring, obstacle spawning and level transitions were all built from scratch, improving as we went.

🧪

Testing

Testing never really stopped. We played the game ourselves constantly and worked through a steady stream of control bugs — getting the feel right took real perseverance.

🌐

Website

Built with HTML, CSS and JavaScript across multiple design drafts, with Kiro helping refine the finer details along the way.

🛠️

Tools We Used

Python Pygame HTML/CSS/JS Kiro
