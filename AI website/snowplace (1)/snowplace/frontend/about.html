Behind the Scenes

How We Made It

💡 The Idea

At the beginning of the month, we came together to brainstorm a design for a protagonist on pixilart, and we combined our four ideas to form a penguin in a cowboy hat, and it took off from there.

🎨 Design

Once we designed our protagonist, we made a storyline and levels, using a mixture of AI and manual design. It turned out to work perfectly

💻 Programming

The game was developed using Python and Pygame library. We built the collision detection, health system, scoring, obstacle spawning and level transitions from scratch, learning and improving as we went.

🧪 Testing

Testing was an ongoing process. We played the game ourselves constantly, and ran into numerous problems and bugs related to controls. Perseverence one of the trickiest things to get right.

🌐 Website

This website was built using HTML, CSS and JavaScript. Multiple drafts were drawn up using different designs, and with the aid of Kiro some details were refined.

🛠️ Tools Used

Python Pygame HTML/CSS/JS Kiro
