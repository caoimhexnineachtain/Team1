Behind the Scenes

How We Made It

From an idea scribbled on paper to a fully playable game — here's the story of how Snow Place Like Home was built.

💡 The Idea

We wanted to create a game that was easy to understand but genuinely fun to play. The concept of a penguin being far from home — and needing to travel through completely different and contrasting environments — gave us a strong visual identity and a clear narrative goal: get home.

🎨 Design

We designed three visually distinct environments — desert, jungle and wild west farm — each with its own colour palette, obstacles and atmosphere. The penguin character and the cowboy villain were designed to be instantly recognisable and fun.

💻 Programming

The game was developed using Python and the Pygame library. We built the collision detection, health system, scoring, obstacle spawning and level transitions from scratch, learning and improving as we went.

🧪 Testing

Testing was an ongoing process. We played the game ourselves constantly, asked others to try it and used their feedback to adjust the difficulty, fix bugs and improve the feel of the controls. Level balance was one of the trickiest things to get right.

🌐 Website

This website was built using HTML, CSS and JavaScript for the front-end, with a Node.js and Express backend connected to a SQLite database. It features a working contact form, live review system and leaderboard.

🛠️ Tools Used

Python Pygame HTML/CSS/JS Node.js Express SQLite
Timeline

Development Timeline

💡 Concept & Planning

The team came up with the penguin adventure concept and mapped out the three environments, characters and core gameplay loop. Story and character designs were sketched out.

🎨 Design & Assets

Character art, environment backgrounds, obstacles and UI elements were created. The visual identity of each level was established using distinct colour palettes and themes.

💻 Core Programming

The Pygame game engine was built — player movement, jumping, collision detection, health system, score tracking and the basic game loop were all coded and tested.

🌍 Level Building

Each of the three levels was built and balanced. Obstacle patterns, ice cube placement and difficulty curves were adjusted repeatedly based on playtesting sessions.

🧪 Testing & Polishing

The team played through the full game repeatedly, fixing bugs, adjusting difficulty and improving the overall feel. Endless Mode was added as a final challenge feature.

🌐 Website Launch

This website was designed and built to showcase the game — including the live review system and leaderboard. The full project was submitted for assessment.
